Venue Host 0.3.0.4

- Rebuilt version metadata for the latest FFXIV/Dalamud patch-day release.
- Hardened the package build script so it stops if dotnet build fails instead of packaging stale output.
- Added release-time version checks across VenueHost.csproj, VenueHost.json, and pluginmaster.json.
- Added package validation for required root files before publishing dist/VenueHost-latest.zip.

Venue Host 0.3.0.3

- Fixed Event Shouts auto timers so final boundary shouts, such as the last :45 shout in a row window, are not skipped if the framework tick lands slightly late.
- Added a small due-time grace window for automatic Event Shouts while still preventing duplicate sends after a shout is queued.

Venue Host 0.3.0.2

- Fixed Event Shouts automatic scheduling so all rows with Auto enabled are considered, regardless of which row is selected.
- Removed the redundant Event Shouts Active column from the table/editor. Auto now controls automatic shout scheduling; the selected row is only for Edit/Remove/Move/Shout Now.
- Clarified the Auto event shouts status text so the selected row is not confused with automatic scheduling.

Venue Host 0.3.0.1

- Rebuilt for the current Dalamud API 15 package after the latest FFXIV/Dalamud update.
- Fixed Staff Schedule timeline logic so staff rows are independent and can overlap.
- Fixed staff rows with earlier start times after later rows being pushed to the next day/outside the staff window.
- Changed Add Staff default time to the first hour of the staff/event window instead of chaining after the previous row.

- Added Event Shouts tab for reusable venue-wide custom shout macros.
- Added Event Shout window as the global automatic shout enclosure.
- Added per-shout Start/End windows so each custom shout can run on its own schedule.
- Added manual Shout Now action for selected custom shouts.
- Added non-blocking Add/Edit Event Shout editor window with macro preview.
- Added FIFO queue spacing for simultaneous Event Shouts so due announcements stagger cleanly.
- Projected Event Shout queue preview now shows expected staggered send times.
- Added Event Shout macro variables for shout names and shout window times.
- Kept the service-based architecture: EventShoutService owns timing, queue state, preview, and send behavior.
- Polished Event Shouts tables and controls to match the existing DJ Lineup and Staff Schedule UI.
